Como jogar

Você é o novo integrante da Mistério S.A. Em cada fase há quatro desafios. Leia a história, escreva o comando SQL e clique em Resolver mistério. Cada desafio vale até 100 pontos: errar tira 20 e usar a dica tira 20 (mínimo de 20).

Use Executar para testar sem valer pontos e Ver tabelas para consultar os dados.

Guia rápido de SQL

ComandoPara que serve
SELECT * FROM tabela;Mostra todas as colunas e linhas
SELECT col1, col2 FROM tabela;Mostra só as colunas escolhidas
... WHERE col = 'texto';Filtra linhas (use AND / OR para combinar)
INSERT INTO t (c1, c2) VALUES (1, 'a');Insere uma linha
